# Site de Sorveteria

Este projeto foi desenvolvido como parte de um trabalho escolar para praticar desenvolvimento web.

## Sobre o projeto
O site simula a página de uma sorveteria, onde o usuário pode visualizar alguns produtos e preencher um formulário para fazer um pedido.

## Estrutura do projeto

- Página inicial
- Formulário de pedido
- Imagens de produtos
- Estilização com CSS

## Tecnologias utilizadas

- HTML
- CSS

## Organização das pastas

css → arquivos de estilo do site  
html → páginas do site  
img → imagens utilizadas  
fontes → fontes usadas no projeto

## Objetivo

Praticar a criação de páginas web, organização de arquivos e estilização com CSS.
